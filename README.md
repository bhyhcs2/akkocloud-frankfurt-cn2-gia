## 先弄清两个计价细节：双向流量、年付单价

## CN2 GIA 这条线路处在什么水平

公开的线路整理给出的口径是：电信去程走 CN2 GIA 直连，经由 59.43 节点；联通去程走 AS4837；移动去程走 CMI；回程三网统一收敛到 CN2 GIA，移动回程已改为 CMIN2。这套“去程各走各的、回程用 GIA 兜底”的做法，用意是晚高峰时少绕路。

拿它和一台已验证过的同类产品比，能看出水位。V.PS 在 2026 年 10 月新增的法兰克福机房，配置 AMD EPYC 7003 + NVMe，三网标称 CN2 GIA / CUP / CMIN2，第三方实测到国内平均延迟 166ms，IPv4 三网回程小包晚高峰 0 丢包、移动大包约 8%，IPv6 走普通路由、晚高峰约 8% 丢包。166ms 在欧洲机房里属于偏低的一档，普通欧洲机房常常 200ms 以上。

有两点不能直接搬过来用。

一是延迟数字。关于 AkkoCloud 的国内延迟，第三方推广文的说法是 150–180ms，和上面 166ms 属于同一量级，但这个数字没有官方来源背书，写文的人也没公开测试方法。自己跑一遍比看任何测评都准，公开的测试 IP 是 185.217.109.94，在本地 ping 一遍、再看一眼 traceroute 回程走不走 59.43，十分钟的事。

二是联通。联通去程走 4837 在德国优化机里算常规操作，V.PS 那台联通去程也是 10099 + 4837 的半优化，回程才走 9929。所以联通用户别指望和电信一个体验，晚高峰的差距主要出在这一段。

IPv6 也要单独确认。套餐表只写了 1 个 IPv4，没有标 IPv6 地址。参照上面那台同类产品的表现，IPv6 往往走普通路由、晚高峰丢包明显高于 IPv4，如果你的业务依赖 IPv6，下单前先问清楚有没有、走不走优化。

## 常见问题

**德国 VPS 需要备案吗？**
服务器在境外，不需要 ICP 备案。但如果你为了国内访问套了国内 CDN，CDN 那一侧通常要备案，这是另一回事。

**晚高峰会不会丢包？**
AkkoCloud 没有公开的晚高峰数据。同类线路的参照值是：IPv4 三网回程小包 0 丢包，移动大包约 8%，IPv6 约 8%。自己用 185.217.109.94 在 20:00–23:00 测一轮，比任何二手结论都可靠。

**续费是同价吗？**
公开套餐表没有区分首期价和续费价，年付 299 元是首年还是长期价，下单页或工单里确认一句。

**能装 Windows 吗？**
KVM 虚拟化，技术上可以。授权要自备，内存至少 2GB 才谈得上能用，512MB 和 768MB 那两档不用考虑。

**流量超了会停机还是限速？**
套餐表没写超额策略。德国商家常见做法是限速而非停机（OVHcloud 亚太机房超额限速 10Mbps 就是这种），但别替商家做假设，下单前问。

**支持哪些付款方式？**
公开信息里没有确认支付宝或信用卡，结账页面看到什么就是什么。
